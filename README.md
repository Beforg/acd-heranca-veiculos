# Atividade de Herança com Veículo | Algoritmos e Classificação de Dados

Disciplina: Algoritimos e Classificacao de Dados

### Aplicação de Herança entre os objetos.
As classes OffRoad e Truck herdam da classe abstrata Vehicle, fazendo a implementação do método abstrato `move()` 

### Estrutura da Atividade

```

heranca-veiculos/src/OffRoad -- Classe filha
heranca-veiculos/src/Truck  -- Classe filha
```
